日期：2026-11-04。开发环境：Windows 10 amd64，便携式 Go 1.26.10，Node.js 24.18.0，CGO 关闭。

- `go vet ./...`：通过。

- Linux amd64 与 arm64 的 CGO_DISABLED 发布构建：通过。
- 系统工具与巡检 Linux 测试二进制交叉编译：通过，不代表实际运行。
- QQ 官方与 OneBot 协议模拟测试多轮通过；路由多轮重复测试通过。
- 本地 HTTP 端到端脚本 **27 项检查全部通过**，只使用模拟模型和独立临时工作目录。

### 端到端检查范围

1. 未登录的 API 与 SSE 拒绝访问。
2. 令牌登录、初始化完成后关闭设置接口。
3. 跨站修改拒绝，保存模型密钥不得用于不同端点测试。
4. 文件写入在批准前无副作用；拒绝后不写；已使用审批不能重放。
5. 再次提议、批准后实际创建测试文件，验证完整内容，结果回填模型。
6. 等待审批的任务可取消，状态持久化，记忆不落库，旧审批失效。
7. 浏览器批准的记忆在重启后仍存在，并可通过中文/英文检索。
8. 退出后旧 Cookie 无效。

首轮端到端测试曾在取消接口收到 ConnectionResetError：任务实际已取消，但未消费调用方附带的 `{}` 请求体。现已修复无请求参数接口的有限请求体消费，重跑 27 项全部通过。

### 浏览器流程（部分 GUI 验证）

实际打开本地站点并走通：设置码验证 → 环境检查 → 本地模型测试返回 OK → 人设与记忆 → 目录 → 双 QQ 配置（不启用） → 默认关闭的值守 → 生成令牌 → 登录 → 任务提议记忆 → 网页展示完整审批 → 批准 → 记忆列表新增记录。服务重启后重新加载，初始化状态和记录保留。

浏览器宿主后续将页面标记为 `document.visibilityState='hidden'`，尽管控件几何正常、点位命中控件，真实指针动作及截图出现超时。后半段使用已观察到的控件进行键盘/DOM 点击，并检查 DOM 和 API 结果。

**没有完成可靠的截图视觉验收及完整移动布局实测，不能把上述功能验证称为完整 GUI 验收。**

## 安全修复回归

只读复核找到并修复：
- 令牌轮换与在途登录竞态：原子 SQL 验证并创建会话。
- 取消排队任务后被运行线程重新领取：同一锁内领取状态。
- JSON 转义和 PEM 私钥主体的脱敏遗漏：先解码结构，递归处理字符串，再序列化。
- 任意模型测试端点读取已保存密钥：强制原端点，模型地址/Key 原子快照。
- 跨进程令牌文件/hash不一致：令牌与hash统一放私有SQLite同一事务。

这不是独立的完整安全审计；Shell 权限仍由 OS 账户约束，运行服务账户被攻破时其数据也可能被读取。

## 明确未验证／限制

- 无可用 Linux/WSL 运行环境：未实测 systemd 安装、Linux指标、Linux进程组退出、权限与资源上限。
- `go test -race` 未运行成功：环境输出 `go: -race requires cgo; enable cgo by setting CGO_ENABLED=1`，且无 C 编译器。并发场景单测不能替代 race detector。
- Windows 创建符号链接测试受系统权限限制而跳过；硬链接等相关测试通过。
- 未连接真实 DeepSeek/其他云端模型，未登录 QQ，未发送真实消息，未验证平台账号权限和公网回调证书。
- 官方 QQ 仅被动文本回复，不支持主动巡检推送；主动通知保留网页。OneBot需用户另外部署网关。
- 文件日志读取上限 1 MiB；不直接提供 journal 日志工具。搜索实际扫描上限 8 MiB、2000项、16层。
- 写文件采用核验后的句柄原位写，保留权限，但**不是断电/崩溃原子替换**；关键配置应另行备份。
- 截图视觉验收与移动端完整交互验证未完成，原因如上。
- 未做负载、渗透、多租户隔离、长期稳定性测试，不应直接用作公网多用户运维平台。

## 相比完整规划的首版取舍

- 模型 HTTP 支持流式解析，但为避免分片凭据泄漏，浏览器以每个完整模型轮次更新可见文本，而非逐token实时呈现；工具进度通过 SSE 更新。
- 上下文使用完整消息组截断和固定预算，没有实现自动模型摘要；任务超预算明确停止。
- 时间线和确定性任务简报已实现；没有独立的模型复盘草稿编辑器、自动日报计划或自动生成运维经验。
- 记忆支持新增、编辑、状态、删除、引用；暂未提供批量清空、通用历史版本对比/回滚面板。
- 值守仅固定CPU/内存/磁盘只读规则，不含任意自定义脚本或自动修复。
- 保留的QQ配置、实例、会话和消息均隔离；配置改变/重启创建新实例会话，旧记录保留网页，不自动把跨实例历史重注入模型。

这些取舍用于保持v0.1轻量和权限清晰，未实现功能没有伪装成完成。

## 本地复现

```sh
node scripts/mock-model.cjs
# 另一个终端运行编译后的程序，使用独立数据/工作目录。
# 配置模型 http://127.0.0.1:7799，名称 mock，密钥任意开发占位值。
# 网页先发送“演示记忆”并批准，建立脚本所需的演示记忆。
python -I scripts/e2e_api.py --data-dir <隔离数据目录> --work-dir <隔离工作目录>
```

端到端脚本会读取本地测试SQLite中的访问令牌，不输出令牌；仅接受127.0.0.1。会在给定工作目录创建`ops-demo.txt`，重复运行只删除内容完全匹配的上次测试文件。不要对生产目录运行该开发脚本。
